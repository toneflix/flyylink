# FlyyLink browser add-on

One add-on for Chrome, Edge, Brave, Firefox and other browsers built on Chrome. It talks to the FlyyLink app on the same computer.

```sh
npm test            # tests for the shared code
npm run build       # dist/chrome and dist/firefox, for loading unpacked
npm run store       # the zips the stores take
```

See [docs/BROWSER.md](../docs/BROWSER.md) for what it does, how it reaches the app, and how to publish it.
